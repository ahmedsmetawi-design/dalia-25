# Dalia's Birthday Journey — Level 25

رحلة خطوة بخطوة: كل دوسة بتطلّع اللي بعدها بأنيميشن، وكل مرحلة ليها أغنية عيد ميلاد مختلفة.

## الترتيب
اللغة ← تحميل (5 جمل × 3.5 ثانية) ← Press Start ← 8 مستويات على خريطة:
1. ركن الرسم (4 ألوان) · 2. الباسبور (4 أختام) · 3. معمل الـ25 (4 كروت + 25 حقيقة + كويز)
4. الحلقة 25 (كلاكيت + 3 مشاهد) · 5. فرقعي 25 بلونة · 6. الهدية + العرض الكبير (particles + ألعاب نارية)
7. التورتة (25 شمعة، دوس أو نفخ في المايك) · 8. رسايل أحمد + الجواب ← النهاية (وضع الحفلة: انزل يا جميل)

## تعديل النصوص والإعدادات — كله في `js/content.js`
- `*كلمة*` ← الكلمة تظهر دهبي وتعمل "بوب"
- `music` ← أنهي أغنية في أنهي مرحلة (الملفات في `assets/audio`)
- `partySong` ← فيديو يوتيوب لوضع الحفلة
- `images` ← صور اختيارية (start / gift / cat) في `assets/img/`

## روابط للتجربة
- `?preview=1` ← يتخطى قفل الساعة 12
- `?reset=1` ← يبدأ من الأول
- `?skip=1` ← يتخطى شاشة التحميل
- `?ch=5` ← يفتح على مستوى معيّن (1–8)
- كيبورد: Enter / Space = دوسة
- ⚠️ ابعتلها اللينك **من غير** أي حاجة من دول.

## المزيكا
